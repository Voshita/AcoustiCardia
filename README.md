# AcoustiCardia

Static connected-care prototype with simulated data.

## Publish on GitHub Pages

1. Create a public GitHub repository named `acousticardia`.
2. Upload the contents of this folder to the repository root. Keep `index.html` at the root, and preserve the `assets` folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, then **main** and **/(root)**. Click **Save**.
5. Once deployment completes, open the URL shown in Pages settings. The usual address is `https://YOUR-USERNAME.github.io/acousticardia/`.

No build command or dependencies are required. Upload future changes to the same branch to update the site.

This prototype uses fictional patients and simulated signals. It does not provide a production backend or persistent clinical records.
